Overview

Ship identifiers and etag tokens for idempotent workflows. Built as a tiny zero-dependency Node toolkit with a library API and a stdin-friendly CLI.

Usage

git clone https://github.com/theworker02/shipetag.git
cd shipetag
node src/cli.js --help
node --test
