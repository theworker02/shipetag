# shipetag

Ship identifiers and etag tokens for idempotent workflows.

**Site:** https://theworker02.github.io/shipetag/

## Install / run

```bash
git clone https://github.com/theworker02/shipetag.git
cd shipetag
node src/cli.js
node --test
```
